# Renaissance Art Gallery 3D 🎨 | Galería Renacentista EBVG

An immersive, interactive 3D web application developed for the art students of the Berta von Glumer School (EBVG). This educational project allows users to navigate through a virtual museum featuring iconic Renaissance masterpieces, learning about history and art techniques through an interactive owl guide.

As a Front-End developer focused on creating interactive 3D experiences, I built this project to demonstrate how web technologies can transform traditional learning into engaging, gamified environments.

### Technologies & Technical Skills
* **Core:** HTML5, CSS3, JavaScript (ES6+)
* **3D Library:** Three.js (WebGL rendering, Lighting, Raycasting, Physics/Collisions)
* **Controls:** PointerLockControls for first-person navigation (Desktop & Mobile touch support)
* **Architecture:** Modular component-based logic, clean separation of concerns, fully responsive UI elements.

# Galería Renacentista 3D 🎨 | EBVG

Una aplicación web inmersiva e interactiva en 3D desarrollada para los estudiantes de arte de la Escuela Berta von Glumer (EBVG). Este proyecto educativo permite a los usuarios navegar por un museo virtual que exhibe obras maestras icónicas del Renacimiento, aprendiendo sobre historia y técnicas artísticas a través de un búho guía interactivo.

Como desarrollador Front-End enfocado en crear experiencias interactivas en 3D, construí este proyecto para demostrar cómo las tecnologías web pueden transformar el aprendizaje tradicional en entornos atractivos y gamificados.

### Tecnologías y Habilidades Técnicas
* **Core:** HTML5, CSS3, JavaScript (ES6+)
* **Librería 3D:** Three.js (Renderizado WebGL, Iluminación, Raycasting, Físicas/Colisiones)
* **Controles:** PointerLockControls para navegación en primera persona (Soporte para PC y modo táctil en móviles)
* **Arquitectura:** Lógica modular, separación limpia de responsabilidades (HTML/CSS/JS) y elementos de interfaz de usuario (UI) totalmente responsivos.

### Installation / Instalación
1. Clone the repository / Clona el repositorio
2. Run / Ejecuta `npm install`
3. Run / Ejecuta `npm start`
